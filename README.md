## Overview

AURELIA is a luxury fine-dining web experience designed to showcase an elegant restaurant brand through sophisticated visuals, refined typography, smooth motion, and an immersive responsive layout.

## Live Link
https://aurelia-fine-dining-six.vercel.app/

## Features

- Luxury dark-themed design
- Gold-accented visual identity
- Responsive layout for mobile, tablet, and desktop
- Smooth animations and transitions
- Interactive user interface
- Modern restaurant marketing experience
- Elegant typography using Playfair Display and Poppins

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/V4Sofronic/aurelia-fine-dining.git
```

Navigate into the project:

```bash
cd aurelia-fine-dining
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your terminal.

## Production Build

Build the project:

```bash
npm run build
```

The production-ready files are generated inside the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```

## Deployment

Deployed using Vercel.

Every push to the connected GitHub repository can trigger an automatic deployment.
